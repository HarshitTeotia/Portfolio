# Portfolio button, link and interaction audit

Audited November 14, 2026 against the local **production static export**, served at `http://127.0.0.1:4173/Portfolio/`. No deployment or push performed. The opportunity/location content changes already in the working tree were preserved.

## Results and counting

- **562 interactive control instances discovered and successfully exercised.** An instance is a route + landmark + accessible name; shared navigation repeated on another route counts separately. Desktop navigation and mobile-dialog navigation are separate variants. Repetitions at different widths are merged below.
- **36 additional technology-to-project state/destination combinations** were exercised individually. These reuse the explorer's related-project links and are not added to the DOM control count.
- **598 passing inventory entries**, representing **2808 viewport/entry exercises**. A technology entry additionally contains mouse, touch, Enter, Space, hover/focus, persistence, toggle, reset and Escape assertions; the number above is not a claim about individual click count.
- **5 confirmed issue categories found; 5 fixed; 0 known unresolved local interaction failures.** Source checks identifying misleading affordances are distinguished from browser functional failures below. Test-authoring mismatches (decorative characters and attempting to refocus an already focused element) were corrected and are not counted as product failures.
- **36 Playwright tests passed**, 0 failed, 0 skipped, 0 flaky. Existing suite: 17; added audit suite: 19. Actual run duration: 355.5 seconds.
- Chromium **153.0.8010.12**, Playwright **1.65.0**, Windows. Browser widths **320, 375, 390, 768, 1024, 1440px** at 900px height for the exhaustive matrices; existing intro tests also use 320×568 and 640×360. Touch emulation at every matrix width. Chromium only; Firefox, WebKit and physical-device/assistive-technology testing **UNVERIFIED**.
- **15 exported route variants**: `/`, `/_not-found/`, `/404.html`, `/404/`, `/about/`, `/contact/`, `/dev/design-system/`, `/episodes/`, `/experience/`, `/projects/`, `/projects/haut/`, `/projects/van-sales-distribution-erp/`, `/projects/viblets/`, `/projects/vrozart-finance/`, `/tech/`. The 11 public routes plus 404 aliases and the production-disabled design showcase are covered. The showcase's development demo controls are absent from production.
