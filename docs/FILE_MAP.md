# FILE_MAP.md

File-by-file inventory of every meaningful source file, based on direct inspection of each file's actual content. Generated files (`.next/`, `node_modules/`, `tsconfig.tsbuildinfo`, `next-env.d.ts`) are excluded — they are rebuilt from source and carry no hand-authored content.

Legend for **Safe to modify**: 🟢 low risk (isolated/local) · 🟡 medium risk (a few consumers, check them) · 🔴 high risk (many consumers or subtle invariants — read [ARCHITECTURE.md](ARCHITECTURE.md) first).
